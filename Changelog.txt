Alpha v2 - IN DEVELOPMENT, ADDITIONS AND CHANGELOG NOT FINALIZED

- Migration to a standalone release
- Made a ModDB page for Containment Breach: Inclemency (https://www.moddb.com/mods/cb-inclemency)

- Changed version naming scheme from "Indev Update X" to Alpha vX.Y.Z

- Heavily re-organized the SFX folder and its subfolders

Gameplay:
- Added four new rooms to the Light Containment Zone
- You can no longer save via quitting on the Keter difficulty
- Being scared and losing blood negatively affects the player's sanity
- Agent Ulgrin no longer hands you SCP-173's document in the intro
- You no longer recieve SCP-173's document when starting a new game with the intro disabled
- Added new achievements: Object of Attention, Oh Shit!, Anklebreaker, To Hell..., ...And Back, Sacrifice, Absconded, Iron Resolve, Go-Fer, Freedom In A Flash
- New "Lighter" and "Lit Cigarette" items: use the Lighter to light a cigarette which you can then smoke
- Removed 'Mods' button from the main menu
- Buffed SCP-1499

Visuals:
- Added extra HUD icon states for blinking, standing still (+ crouched variant), and walking
- Completely removed all custom lightmaps due to various issues
- Visual effects for low sanity (slight screen shake + blur)
- Remastered whitewall and officewall to have a higher resolution
- Changed the textures for smoke and smoke2
- Changed the textures for metal3, metal, and metal_darker
- Tweaked viewbob intensity and speed to resemble a more normal walking gait and match the footstep speed

Audio:

- Expanded the footstep sound system dramatically with randomized foley, more footstep variation and more materials

- Added different sound effects for different inventory interactions
- Added a new inventory sound effect category for cards and badges

- Added a large variety of new breathing sound effects (+ gas mask variants)

- Added a sound effect that plays when viewing a clickable monitor

- Added special sounds when getting hit and dying while wearing a hazmat suit
- Remastered the end dialogue for Ending B2
- Lowered the volume of the tesla gates' sound effects
- Brought back the proper PowerUp.ogg sound for tesla gates (previously re-used WindUp.ogg)
- Different body fall sound effect for the 895 suicide guard event

Miscellaneous:
- Various changes and tweaks to many text strings
- Added a new intro video
