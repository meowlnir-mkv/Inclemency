# Containment Breach: Inclemency

A work-in-progress mod for SCP – Containment Breach which aims to provide a better experience for the game without comprimising its original identity through overhauled or new content and systems.  
Based off of [SCP-CB-CPP/scpcb](https://github.com/SCP-CB-CPP/scpcb).

Inclemency and its code is licensed under the [Creative Commons Attribution-ShareAlike 3.0 License](https://creativecommons.org/licenses/by-sa/3.0/), as it's a derivative work of [the SCP Foundation collaborative writing project](https://scp-wiki.wikidot.com/).

Requirements:
-	[BlitzX3D](https://github.com/Team-X3D/BlitzX3D)
-	[CBRE-EX](https://github.com/AnalogFeelings/cbre-ex) for room editing/creating

Beware: The source code is much more frightening than the game it creates...
