# Containment Breach: Inclemency

An overhaul mod for SCP – Containment Breach. https://www.moddb.com/mods/cb-inclemency

Containment Breach: Inclemency and SCP – Containment Breach are based on [the works of the SCP Foundation community](https://scp-wiki.wikidot.com/).
Based off of [SCP-CB-CPP/scpcb](https://github.com/SCP-CB-CPP/scpcb).
Licensed under the [Creative Commons Attribution-ShareAlike 3.0 License](https://creativecommons.org/licenses/by-sa/3.0/).

Requirements:
-	[BlitzPRO Legacy](https://github.com/Euclid-Labs-Studio/BlitzPRO/releases/tag/legacy-v2.100)
-	[CBRE-EX](https://github.com/AnalogFeelings/cbre-ex) for room editing/creating

> [!IMPORTANT]
> Make sure to copy all .decls files from this repo's `Userlibs` folder to your Blitz3D installation's `userlibs` folder before compiling.

Beware - the source code is perhaps more horrifying than the game itself!
